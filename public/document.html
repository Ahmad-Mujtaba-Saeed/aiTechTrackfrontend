1. Overview

This document covers two complete ways to deploy PathForge (backend + frontend) on a VPS: using Docker Compose, or manually without Docker, served through Nginx.

Each setup video below is paired with the exact written steps used in it. Replace placeholders such as <VPS_IP>, <VPS_USER>, <BACKEND_REPO_URL> and <FRONTEND_REPO_URL> with your actual values throughout.

REQUIRES

A VPS with SSH access (Ubuntu 22.04 / 24.04 recommended) is required for both deployment paths.

2. Deployment with Docker

This path covers deploying both the backend and the frontend on a VPS using Docker Compose.

Service URL Port
Backend http://<VPS_IP>:8585 8585
Frontend http://<VPS_IP>:8485 8485

2.1 Prerequisites

  • A VPS with SSH access (Ubuntu 22.04 / 24.04 recommended)
  • SSH credentials (password or private key)
  • Git installed on the VPS
  • Docker Engine and the Docker Compose plugin installed on the VPS
  • Ports 8585 and 8485 open in the firewall / cloud provider security group

Verify (or install) the prerequisites

SSH into the server first, then check what's already installed:

git --version
docker --version
docker compose version

If Docker is missing, install it:

# Update package index
sudo apt update && sudo apt upgrade -y
 
# Install prerequisites
sudo apt install -y ca-certificates curl gnupg git
 
# Add Docker's official GPG key
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
sudo chmod a+r /etc/apt/keyrings/docker.gpg
 
# Add the Docker repository
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] \
  https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo "$VERSION_CODENAME") stable" \
  | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
 
# Install Docker Engine + Compose plugin
sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
 
# Allow running docker without sudo (log out and back in afterwards)
sudo usermod -aG docker $USER
newgrp docker

Open the required ports (if UFW is enabled):

sudo ufw allow 8585/tcp
sudo ufw allow 8485/tcp
sudo ufw reload
sudo ufw status

Setting up Backend in VPS via Docker

Part 1 of the Docker deployment guide

Step 1 — SSH into the VPS

ssh <VPS_USER>@<VPS_IP>

# Example:
ssh root@203.0.113.45

# If you use a private key:
ssh -i ~/.ssh/your_key.pem <VPS_USER>@<VPS_IP>

Step 2 — Go to the directory where the project should live

# Example: use /var/www as the deployment root
cd /var/www
 
# Create it if it doesn't exist
sudo mkdir -p /var/www
sudo chown -R $USER:$USER /var/www
cd /var/www
 
# Confirm where you are
pwd

Step 3 — Clone the backend repository

git clone <BACKEND_REPO_URL>

# Private repo options:
git clone https://<USERNAME>:<TOKEN>@github.com/<org>/<backend-repo>.git
# or
git clone git@github.com:<org>/<backend-repo>.git

Step 4 — Enter the project directory

cd <backend-project-folder>
ls -la

You should see docker-compose.yml, Dockerfile, and .env.example.

Step 5 — Create the .env file from the example

cp .env.example .env
ls -la .env

Step 6 — Configure the .env file

Open the file in an editor: nano .env

6a. Database credentials — keep the Docker defaults matching the Docker Compose database service.

DB_CONNECTION=mysql
DB_HOST=db             # <- Docker service name, NOT localhost
DB_PORT=3306
DB_DATABASE=app_db
DB_USERNAME=app_user
DB_PASSWORD=secret
COMMON MISTAKE: Setting DB_HOST=localhost inside container refers to itself. Always use the Compose service name (e.g., db).

6b. Add your API keys (optional):

STRIPE_KEY=
STRIPE_SECRET=
OPENAI_API_KEY=
MAIL_HOST=
MAIL_USERNAME=
MAIL_PASSWORD=

6c. Save and exit: Press Ctrl + O, then Enter, then Ctrl + X.

Step 7 — Build and start the backend containers

docker compose up --build -d

Step 8 — Verify the backend is running

docker compose ps
docker compose logs -f
curl -I http://localhost:8585

Step 9 — Access the backend

Open in your browser: http://<VPS_IP>:8585

Setting up Frontend on VPS via Docker

Part 2 of the Docker deployment guide

Step 1 — SSH into the VPS

ssh <VPS_USER>@<VPS_IP>

# Example:

Step 2 — Go to the deployment directory

cd /var/www

Step 3 — Clone the frontend repository

git clone <FRONTEND_REPO_URL>

Step 4 — Enter project directory

cd <frontend-project-folder>

Step 5 — Build and start the frontend containers

docker compose up --build -d

Step 6 — Verify frontend

docker compose ps
curl -I http://localhost:8485

Step 7 — Access frontend

Open in browser: http://<VPS_IP>:8485

2.4 Post-Deployment Checklist (Docker)

  • docker compose ps shows backend containers Up
  • docker compose ps shows frontend containers Up
  • http://<VPS_IP>:8585 loads backend
  • http://<VPS_IP>:8485 loads frontend
  • Frontend can successfully call backend (check browser Network tab)
  • Ports 8585 & 8485 open in firewall

2.5 Common Management Commands

docker compose ps
docker compose logs -f
docker compose logs -f <service-name>
docker compose down
docker compose down -v
docker compose restart
docker compose exec <service-name> bash

2.6 Deploying Updates

cd /var/www/<project-folder>
git pull origin main
docker compose up --build -d

2.7 Troubleshooting (Docker)

Port already in use:

Run sudo lsof -i :8585 or change host port mapping in docker-compose.yml.

Backend can't connect to database:

Confirm DB_HOST matches DB container service name, check docker compose ps.

Rebuild without cache:

docker compose build --no-cache && docker compose up -d

Deploying Laravel (Backend) and Node.js (Frontend) directly on a VPS, served via Nginx.

Frontend Node.js 22 (built to static) Nginx (static build output)

3.1 Prerequisites

sudo apt update && sudo apt upgrade -y
sudo apt install -y git curl unzip nginx

Setting up Backend on VPS without Docker

Part 1 of the manual deployment guide — Laravel

Step 1 — SSH into VPS

ssh <VPS_USER>@<VPS_IP>

Step 2 — Install PHP, Composer & MySQL

# Install PHP
sudo apt install -y php php-fpm php-cli php-mysql php-mbstring php-xml php-curl php-zip php-gd php-bcmath php-tokenizer

# Install Composer
curl -sS https://getcomposer.org/installer | php
sudo mv composer.phar /usr/local/bin/composer

# Install MySQL
sudo apt install -y mysql-server
sudo systemctl enable --now mysql
sudo mysql_secure_installation

Step 3 — Create Database & User

sudo mysql -u root -p

-- Inside MySQL:
CREATE DATABASE app_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'app_user'@'localhost' IDENTIFIED BY 'your_strong_password';
GRANT ALL PRIVILEGES ON app_db.* TO 'app_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;

Steps 4 to 8 — Clone, Install & Configure .env

cd /var/www
git clone <BACKEND_REPO_URL>
cd <backend-project-folder>
cp .env.example .env
nano .env
SECURITY: Set APP_DEBUG=false in production!

Steps 9 to 13 — Composer, Keys, Migrations & Permissions

composer install --no-dev --optimize-autoloader
php artisan key:generate
php artisan migrate --force
php artisan db:seed --force

# Permissions for storage/cache
sudo chown -R www-data:www-data storage bootstrap/cache
sudo chmod -R 775 storage bootstrap/cache

Step 14 — Install Python & OCR Tools

sudo apt install -y python3 python3-pip python3-venv poppler-utils tesseract-ocr
pip3 install pdf2image pytesseract pillow --break-system-packages

Step 15 — Configure Nginx for Backend

sudo nano /etc/nginx/sites-available/backend
server {
    listen 8585;
    server_name <VPS_IP>;
 
    root /var/www/<backend-project-folder>/public;
    index index.php;
 
    charset utf-8;
    client_max_body_size 50M;
 
    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }
 
    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/var/run/php/php8.2-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
        fastcgi_read_timeout 300;
    }
 
    location ~ /\.(?!well-known).* {
        deny all;
    }
 
    error_log   /var/log/nginx/backend-error.log;
    access_log /var/log/nginx/backend-access.log;
}
sudo ln -s /etc/nginx/sites-available/backend /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
sudo ufw allow 8585/tcp

Setting up Frontend on VPS without Docker

Part 2 of the manual deployment guide — Node.js

Step 2 — Install Node.js v22 via NVM

curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
source ~/.bashrc
nvm install 22
nvm use 22
node -v

Steps 3 to 8 — Clone & Build

cd /var/www
git clone <FRONTEND_REPO_URL>
cd <frontend-project-folder>
npm install
cp .env.example .env
# Set VITE_API_URL=http://:8585 inside .env
npm run build

Step 9 — Configure Nginx for Frontend

sudo nano /etc/nginx/sites-available/frontend
server {
    listen 8485;
    server_name <VPS_IP>;
 
    root /var/www/<frontend-project-folder>/dist;
    index index.html;
 
    location / {
        try_files $uri $uri/ /index.html;
    }
 
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff2?)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
 
    gzip on;
    gzip_types text/css application/javascript application/json image/svg+xml;
 
    error_log     /var/log/nginx/frontend-error.log;
    access_log /var/log/nginx/frontend-access.log;
}
sudo ln -s /etc/nginx/sites-available/frontend /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
sudo ufw allow 8485/tcp

3.4 Optional — Domain & HTTPS

Setup Certbot for SSL encryption:

sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d api.yourdomain.com -d app.yourdomain.com
sudo certbot renew --dry-run

3.5 Post-Deployment Checklist (Manual)

  • php, composer, node versions report correctly
  • MySQL Database exists & .env connects
  • APP_KEY populated & migrations ran
  • permissions set on storage & bootstrap/cache
  • Python packages and system tools (poppler, tesseract) work
  • sudo nginx -t succeeds
  • http://<VPS_IP>:8585 and http://<VPS_IP>:8485 both load

3.6 Deploying Updates (Manual)

Backend Update cd /var/www/<backend-folder> git pull origin main composer install --no-dev --optimize-autoloader php artisan migrate --force php artisan config:cache php artisan route:cache sudo systemctl reload php8.2-fpm
Frontend Update cd /var/www/<frontend-folder> git pull origin main npm install npm run build

3.7 Useful Commands

# Nginx
sudo nginx -t && sudo systemctl reload nginx
sudo tail -f /var/log/nginx/backend-error.log

# Laravel logs & clear cache
php artisan config:clear
tail -f storage/logs/laravel.log

3.8 Troubleshooting (Manual)

• 500 Error: Check permissions (chown -R www-data:www-data storage) or check storage/logs/laravel.log.

• 502 Bad Gateway: Verify fastcgi_pass socket path in Nginx matches ls /var/run/php/.

• Frontend routes 404 on refresh: Ensure try_files $uri $uri/ /index.html; is present in Nginx frontend config.
